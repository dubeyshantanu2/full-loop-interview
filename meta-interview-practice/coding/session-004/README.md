# AI-Native Coding — Session 004

## Valid Palindrome II (Two Pointers)

You are joining a content processing team that needs to validate user handles and content strings under fuzzy matching rules.

### Stage 1

Implement `validPalindrome(s)` in `src/validPalindrome.js`:

- Accepts a string `s` consisting of lowercase English letters.
- Returns `true` if `s` is already a palindrome, or can become a palindrome after deleting **at most one** character.
- Returns `false` otherwise.
- The solution should operate in $O(n)$ time and $O(1)$ auxiliary space.

Use the starter tests as your baseline. Inspect the problem, discuss your approach, and verify your implementation.
