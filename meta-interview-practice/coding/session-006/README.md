# AI-Native Coding — Session 006

## 3Sum (Two Pointers)

You are implementing a financial reconciliation utility that detects triplets of balanced transactions summing to zero.

### Stage 1

Implement `threeSum(nums)` in `src/threeSum.js`:

- Accepts an integer array `nums`.
- Returns all unique triplets `[nums[i], nums[j], nums[k]]` such that `i != j`, `i != k`, `j != k`, and `nums[i] + nums[j] + nums[k] === 0`.
- The returned list must **not** contain duplicate triplets.
- The solution should achieve $O(n^2)$ time complexity and $O(1)$ auxiliary space (ignoring sorting/output space).

Use the starter tests as your baseline. Inspect the problem, discuss your approach, and verify your implementation.
